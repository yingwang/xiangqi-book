## 适合谁读

本书不再重复罗列象棋的基础走法规则，亦不铺陈楚河汉界的历史掌故，而是直接切入棋艺进阶的核心命题：如何在实战中建立系统的攻防思维。

通读全书并完成相应推演练习后，读者将在以下维度建立扎实能力：

- 能够看懂高水平对局谱录，准确领会关键着法背后的战略意图。
- 在业余对局中保持稳定的攻防胜率，不再轻易被双车错、马后炮等经典杀型所伏击。
- 面对常见的开局阵型，明晰后续展开的协调出子原则，摆脱盲目随性的随手棋。
- 在残局阶段能够准确计算胜和边界，避免在多子优势下因微小误判被逼和。

## 怎么用这本书

最理想的研读方式是循序渐进。每章末尾皆配有针对性例题，阅读解析前建议先遮挡答案，独立推演至少半分钟以上，再对照参考思路。

杀法与战术本质上是对棋盘空间几何与子力协同的深度直觉。若仅停留在理论阅读而不亲自动手拆解，实战中依然容易出现视而不见的认知盲区。每日保持适量的杀法习题推演，对棋感的敏锐度提升远胜单纯的理论浏览。

## 记谱法

全书统一遵循通行的"四字记谱法"。红方记谱采用汉字数字（一至九，自右向左），黑方采用阿拉伯数字（1 至 9，自左向右），即双方均以己方右手一侧为起点起算。核心动词包含三类：

- **平**：横向移动。第四字表示目标纵线。例如 `炮二平五`，表示二线红炮横向移动至五线（中线）。
- **进**：向前移动。第四字表示移动步数（车、炮、兵卒直行按步数计），或目标纵线（马、相、士斜行则直接标示目标纵线）。例如 `车一进四`，表示一线红车直进 4 格。
- **退**：向后移动。规则与"进"相同，方向相反。

当同一纵线上存在两枚同名棋子时，以"前"与"后"代替起始纵线以示区分，例如 `前马进七`。

更为详尽的记谱规范与变例，可参阅本书[附录](99-术语对照.md)。
