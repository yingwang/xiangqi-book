## 适合谁读

本书不再重复介绍象棋的基本规则，也不展开讲解楚河汉界背后的历史故事，而是直接进入"如何把一盘棋下好"这一核心问题。

完整读完本书之后，读者应当能够做到以下几件事：

- 看懂职业棋手公开的棋谱，能够大致理解每一步棋背后的真实意图。
- 在朋友局之中保持稳定的胜率，不再轻易被双车错、马后炮这一类常见杀法击倒。
- 拿到一个具体开局之后，知道接下来几步的合理走法，而不是仅凭感觉随意出子。
- 在残局阶段能够独立计算清楚胜负与和棋的判定，避免出现"明明子力领先，却被对方逼成和棋"的局面。

## 怎么用这本书

最理想的方式是按顺序通读全书。每一章后面都附有几个例题，看完讲解之后建议先把答案盖住，认真思考至少三十秒以上，再去对照参考解答。

杀法和战术从本质上看是一种肌肉记忆，而不是单纯的知识体系。如果只是反复阅读理论而不动手做题，到了实战之中仍然会出现"看不见杀棋"的瞬间。每天花十分钟左右做几道杀法题，所带来的提升远远超过同等时间阅读理论。

## 记谱法

全书统一使用中国通用的"四字记谱法"。红方在记谱时使用汉字数字（一到九，自右至左），黑方使用阿拉伯数字（1 到 9，自左至右），换言之，双方都从己方右手一侧开始计数。动词一共只有三个：

- **平**：横向移动。第三个字代表目标纵线。例如 `炮二平五`，表示红方右炮（二线）横向移动到中线（五线）。
- **进**：向前移动。第三个字代表步数（车、马、炮、兵的进退按步数计算），或者目标纵线（马、相、士因为走的是斜线，另行处理）。例如 `车一进四`，表示一线红车前进 4 格。
- **退**：向后移动。规则与"进"相同，只是方向相反。

当同一线上同时存在两颗同名棋子时，用"前"与"后"来代替起始线进行区分，例如 `前马进七`。

更详细的记谱规则可以参见本书的[附录](99-术语对照.md)。
